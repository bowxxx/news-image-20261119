A program that draws a one-day newspaper poster summing up Thursday 19 November 2026's world news: the ICJ's genocide ruling against Myanmar, the first Trump–Xi–Putin summit in Shenzhen, GTA 6's launch, Anthropic's record IPO, the Houthi strike on Riyadh's PIF Tower, the third strike on the Crimean Bridge, and the end of Israel's Gaza tank raid. It renders its own 5×7 bitmap font, vector pictograms and PNG encoder — no image files, no network, fully deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
